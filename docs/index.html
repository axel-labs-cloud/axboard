home.lab / dashboard

What you get

Everything to run your services from one screen.

Live where it matters, quiet everywhere else — the board refreshes itself and gets out of your way.

Widgets

80+ widgets, six categories

Service panels (Proxmox, *arr, Jellyfin, Immich, qBittorrent…), a full Home Assistant suite, host metrics, content feeds (Reddit, HN, YouTube) and a custom-API builder — most re-layout as you resize them.

Deploy

One binary

Go server with the SPA embedded. Drop it on a box, point it at a YAML file, done.

Config

YAML you own

Your config is a human file the server only reads. Layouts live separately, so dragging never touches your comments.

Monitor

Live health checks

HTTP, TCP, ping, DNS and push heartbeats — with 24h / 7d / 30d uptime and retry gating.

Alert

Down & recover

ntfy, Telegram, email or webhook. Resend, mute, maintenance pause, and cert-expiry warnings.

Share

Status pages

Server-rendered, themeable public status pages with criticality-aware severity and an embeddable badge.

Theme

Genuinely themeable

Built-in dark & light themes, a custom-theme creator, per-dashboard backgrounds, glass widget styling, fonts and a custom-CSS box.

Operate

Keyboard-first

A ⌘K command palette across apps, bookmarks, commands and web search — plus a full shortcut cheat sheet.

Install

PWA

Add it to your phone or desktop; the shell loads instantly and works offline.

Secure

Optional login

Open by default. Opt into an argon2id login with signed-cookie sessions when a proxy isn't in the picture.

home.lab / dev

Themes & dashboards

One board is never enough.

Add as many dashboards as you like — switched by tabs and each addressable by its own URL. Give every board its own accent, background and layout.

Built-in themes, a custom-theme creator, glassmorphism widget styling and a custom-CSS box mean each one can look like its own thing.

Status pages

A status page that means something.

Group your services, show real uptime, and colour the summary by severity. A critical service down goes red; non-critical outages go amber and escalate past a threshold you set.

Gate it behind a login, or flip one page public to share while the rest of the dashboard stays private.

status.lab / status

Kept small on purpose

What axboard is not.

not a metrics storeHealth checks are liveness only. Point at Grafana for real observability.
not a plugin platformThe widget registry is internal. New widgets land via PR, not a runtime API.
not multi-tenantOne YAML config, one trust boundary. Put a proxy in front for anything more.

Up in about a minute.

Clone, copy the example config, and bring it up. Then edit the YAML — it hot-reloads on save.

$ podman compose up -d
