# Widget example screenshots

Drop a PNG here named after the widget's **type** and it appears automatically
under that widget in [docs.html](../docs.html) — expand the widget to see it.

- Filename = the `type` shown in the widget's grey pill in the docs, e.g.
  `proxmox.png`, `halights.png`, `weather.png`, `hasensors.png`.
- Only the widgets you screenshot get an image; the rest simply show none.
- The image loads lazily when a reader expands that widget (no image → no request shown).

Recommended: capture the widget at (or near) its **default** grid size on a dark
theme, PNG, roughly 2× for crispness. Keep each file well under ~300 KB.

The widget's default size and resize range are already shown in the docs above
each example (from the widget definition), so a single representative shot is
enough — no need to capture every size.
